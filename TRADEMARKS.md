# Project Identity

`task-api-router` and `Task API Router` identify the official project at:

<https://github.com/2649895039-blip/task-api-router>

The source code is MIT-licensed. That license permits reuse, modification,
and redistribution when its copyright and license notices are retained.

Reuse of the project name, repository URL, badges, screenshots, release
numbers, or maintainer identity must not suggest that a fork is official,
endorsed, or supported by the maintainers. A modified distribution should use
its own product name and identify itself as a fork in its README and package
metadata.

This policy does not remove any rights granted by `LICENSE`; it defines how
the project's names and identity may be represented.
